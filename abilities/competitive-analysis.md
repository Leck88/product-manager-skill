# 竞品分析能力

## 能力描述

系统性地分析竞争对手产品，识别市场机会、借鉴优秀实践、规避对手陷阱，为产品差异化策略提供决策依据。

---

## 竞品分析框架

### 第一步：明确分析目的

在开始分析前，先回答这三个问题：
1. **我想解决什么问题？**（功能设计参考？市场定位？还是商业模式？）
2. **我期望得出什么结论？**
3. **谁会看这份报告，他们关心什么？**

---

### 第二步：选定分析对象

**竞品分类**

| 类型 | 定义 | 示例 |
|------|------|------|
| 直接竞品 | 同类产品，目标用户高度重叠 | 微信 vs 钉钉（企业通讯） |
| 间接竞品 | 不同形态，解决相同问题 | 外卖 vs 便利店（解决吃饭问题） |
| 参考产品 | 不同行业，但有可借鉴的设计 | 银行APP学习电商的体验 |

**选择建议**
- 直接竞品：分析 3-5 个
- 参考产品：1-2 个即可

---

### 第三步：分析维度

#### A. 产品定位分析
```
- 核心价值主张（一句话）
- 目标用户群体
- 差异化卖点
- 品牌调性
```

#### B. 功能对比分析

| 功能模块 | 我方 | 竞品A | 竞品B | 备注 |
|---------|------|-------|-------|------|
| 核心功能1 | ✅/❌/🔄 | | | |
| 核心功能2 | | | | |

图例：✅ 已有 ❌ 没有 🔄 部分支持

#### C. 用户体验分析

从用户旅程的每个阶段评估：
- **首次印象**：应用市场描述、截图
- **新手引导**：注册流程、引导完善度
- **核心流程**：完成核心任务的路径长度
- **交互细节**：反馈机制、动效、错误处理
- **视觉风格**：界面整洁度、一致性

**体验评分（1-5分）**
| 维度 | 竞品A | 竞品B | 我方 |
|------|-------|-------|------|
| 易用性 | | | |
| 完整性 | | | |
| 视觉 | | | |

#### D. 商业模式分析
```
- 盈利模式：免费/订阅/广告/交易抽佣
- 定价策略：
- 用户增长策略：
- 核心护城河：
```

#### E. 数据表现（可获取时）
```
- 应用市场评分/评论数
- App Store/应用宝 排名
- 估算 MAU/DAU
- 用户评价高频关键词
```

---

### 第四步：SWOT 分析

|  | 有利 | 不利 |
|--|------|------|
| **内部** | 优势 (S) | 劣势 (W) |
| **外部** | 机会 (O) | 威胁 (T) |

---

### 第五步：差异化建议

从竞品分析中提炼出：

1. **可以借鉴的点**：竞品做得好的，我们可以学习
2. **竞品的空白点**：用户抱怨的、没人做好的
3. **差异化机会**：我们能做而竞品难以复制的

---

## 竞品信息来源

| 来源 | 获取内容 |
|------|---------|
| 应用商店页面 | 描述、截图、评分、用户评价 |
| 官网 | 产品定位、功能介绍、定价 |
| 用户评价 | 真实痛点、满意点（App Store、各大平台） |
| 竞品试用 | 功能细节、体验感受 |
| 行业报告 | 市场数据、趋势 |
| 公开数据 | 融资信息、团队规模 |
| 社交媒体 | 用户口碑、运营策略 |
