# 命令：/访谈

## 触发方式
- `/访谈`
- "帮我设计访谈提纲"、"用户访谈怎么做"

## 执行步骤

### Step 1：了解研究背景
询问：
1. 这次访谈想了解什么？（研究目的）
2. 受访用户是哪类人？（用户画像）
3. 有多少时间进行访谈？（30分钟/60分钟）
4. 有哪些核心假设需要验证？

### Step 2：生成访谈提纲

按以下结构输出：

```
1. 暖场（5分钟）：开场白 + 2个轻松问题
2. 背景了解（10分钟）：4个背景性问题
3. 核心探索（30分钟）：5-6个核心问题 + 追问指引
4. 痛点深挖（10分钟）：STAR法则还原场景
5. 收尾（5分钟）：开放性问题 + 感谢
```

### Step 3：提供访谈技巧提示

```markdown
## 访谈注意事项

✅ 要做的：
- 多问"上次/最近一次是什么时候"，让用户描述真实行为
- 保持沉默，让用户讲完再追问
- 追问"为什么"，挖掘行为背后的动机

❌ 不要做的：
- 不要用是/否问题
- 不要暗示期望答案（"你觉得这个功能好不好？"）
- 不要打断用户说话
- 不要急于推销你的解决方案
```

### Step 4：提供记录表模板
输出简版访谈记录表，方便现场记录。
